# login-project
Sistema de autenticación de usuarios realizado con HTML, CSS, PHP y Mysql.

Funcionalidades

Autenticación
Formulario de login con usuario y contraseña
Verificación de credenciales contra base de datos
Contraseñas almacenadas con hash bcrypt
Detección de cuenta desactivada
Mensajes de error genéricos 

Sesiones
Inicio de sesión con variables de sesión
Regeneración de ID de sesión al entrar
Cierre de sesión completo con destrucción de cookie
Redirección automática si ya hay sesión activa

Interfaz
Diseño responsive (móvil y escritorio)
Mensajes visuales de error y éxito
Checkbox "Recuérdame"
Enlace "¿Olvidaste tu contraseña?"

Base de datos
Script SQL completo listo para importar
Tabla usuarios con campos de control (activo, fecha creación, último acceso)
Tabla sesiones_log para auditoría de accesos
3 usuarios de prueba incluidos

Instalación. La aplicación web se despliega en local utilizando XAMPP
